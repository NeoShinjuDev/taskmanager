TaskManager - third-party components
====================================

This file lists the third-party libraries, assets and external components that
TaskManager uses. TaskManager itself is covered by the license in the LICENSE
file; the components below keep their own licenses, which apply to them only.

It was written by hand from Cargo.toml (direct dependencies only). The complete
list including transitive dependencies and the full license texts can be
generated from the source tree with, for example:

    cargo install cargo-about
    cargo about init
    cargo about generate about.hbs > THIRD_PARTY_FULL.html

(Please double-check the licenses against each crate's own repository before
redistributing a build; crate licenses can change between versions.)

3. External components loaded or contacted at run time (NOT included)
---------------------------------------------------------------------

None of these files are shipped with TaskManager. The program only uses them if
they are present on the user's computer.

* Windows system APIs and DLLs (kernel32, user32, advapi32, dwmapi, pdh, wtsapi32,
  gdi32 ...) - part of Microsoft Windows.
* Windows Event Tracing (ETW), provider Microsoft-Windows-Kernel-Network - used to
  measure per-process network traffic (needs administrator rights).
* AMD Display Library, atiadlxx.dll - installed by the AMD graphics driver; loaded
  at run time for AMD GPU temperatures, clocks and fan speed.
* NVIDIA NVML, nvml.dll - installed by the NVIDIA graphics driver; used only in
  builds made with the optional "nvidia" feature.
* LibreHardwareMonitor (MPL-2.0) - OPTIONAL, run separately by the user; TaskManager
  can read CPU temperatures from its local web server. No LibreHardwareMonitor code
  or binary is included.
